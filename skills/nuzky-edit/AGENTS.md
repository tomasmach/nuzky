# Nuzky editing

Use the configured Nuzky MCP server to inspect, edit and export this project. Read `nuzky://guide` first. Never edit project JSON directly or overwrite source media. All times are integer microseconds. Plan from the transcript and analysis, group edits in one run, use ripple deletion to keep tracks aligned, build short captions, inspect actual frames and wait for export completion. Report uncertainty instead of claiming an unchecked result.
